INVESTIGATION
typed console.log(customers); into the console
Result: [{name:"Bob"}]

Typed console.log(customers[1]); into the console
Result: undefined

Console error: Cannot read properties of undefined
The code crashed on the line:
customers[1].name

ROOT CAUSE
The customers array existed, but it only contained one customer.
customers[1] returned undefined because index 1 did not exist. 
Javascript then attempted to access: 
undefined.name
which caused the error. 

LESSON LEARNED
Before using customers[1], verify that a second customer exists in the array. Do not assume that an 
array contains a specific index.
