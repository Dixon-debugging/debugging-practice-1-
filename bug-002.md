Bug 002

PROBLEM

JavaScript crashed when trying to convert a customer's name to uppercase.

ERROR

Uncaught TypeError: Cannot read properties of undefined

INVESTIGATION

typed in console.log(customer); into console
Result: {} //empty object

typed in console.log(customer.name); into the console
Result: undefined

ROOT CAUSE  
The customer object existed but it did not contain a name property.
customer.name returned undefined.
Javascript then tried to run: 
undefined.toUpperCase() which caused the error.

LESSON LEARNED
Before using .toUpperCase(), verify that the value is a string and not undefined.
